# Teacher Knowledge Base Management — Stage 17

New route: `/knowledge-base`

The teacher can now:

- upload PDF/DOCX materials;
- optionally bind a material to a task;
- automatically create embeddings after upload;
- see processing and embedding statuses;
- inspect chunks and their embedding state;
- rename/rebind a material;
- reprocess a material;
- regenerate embeddings;
- permanently delete a material;
- test semantic search from the dashboard.

The teacher sidebar now includes **Bilimlar bazasi**.
